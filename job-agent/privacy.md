# Privacy Policy — job agent desktop

*Last updated: October 20, 2026*

"job agent desktop" is a personal tool built and used only by Chinmay Arora
(chinmayarora2001@gmail.com). It is not offered to the public.

**What it accesses.** With the account owner's consent (Google OAuth), the tool reads and
writes Google Sheets that the owner already uses to track job applications and outreach
(scope: `spreadsheets`), and files it creates itself (scope: `drive.file`).

**How data is used.** Sheet data is used only to prepare and track the owner's own job
applications. It is processed on the owner's computer.

**Sharing.** No data is sold, shared with third parties, or used for advertising. Nothing
is collected about anyone other than the account owner and the contacts the owner
records in their own sheets.

**Storage and deletion.** The OAuth token is stored only on the owner's computer. Access
can be revoked at any time at https://myaccount.google.com/permissions, and deleting the
local token file removes all stored credentials.
