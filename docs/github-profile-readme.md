## Featured work

### [Healthcare Risk, Fairness and Calibration](https://github.com/ChinmayA301/Risk-Prediction-with-Fairness-Geography)

**Status: Completed analysis.** Evaluated 101,766 real de-identified encounters with leakage control, calibration, subgroup errors, SHAP, and a model card. A measured 0.44 age-group false-negative-rate gap supports the documented recommendation not to deploy as-is.

### [Tabular ML Reliability Benchmark](https://github.com/ChinmayA301/Tabular-ML-Benchmark-Human-Feature-Engineering-vs-AutoML-Agentic-Baselines)

**Status: Completed analysis.** Designed a config-driven benchmark of five pipelines across three real domains and random/shifted splits. Preprocessing added up to 0.19 AUC while tuning and AutoML added almost no mean lift under the tested conditions.

### [Operations Control Tower](https://github.com/ChinmayA301/Operations-Control-Tower)

**Status: Completed analysis.** Built a DuckDB star schema, data-quality gates, supplier-risk logic, and five-page Looker Studio decision flow over 98,666 real orders. Late orders were 6.5× more likely to receive a 1–2-star review.

### [PolyRAG](https://github.com/ChinmayA301/PolyRAG)

**Status: Deployed demo.** Built a citation-grounded RAG workflow that gives multiple models the same retrieved evidence, separating retrieval quality from generation behavior. Includes ingestion, OCR fallback, FAISS retrieval, evaluation, FastAPI, Docker, and a [live demo](https://chinmaya301-polyrag.hf.space).
